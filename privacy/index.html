隱私權政策

更新日期：2026 年 11 月 22 日

本政策說明 TagBible 在提供每日讀經、個人雲端同步、小組互動與問題回報時，如何取得、使用、保存及分享資料。

一、使用與保存哪些資料

  • Google 登入資訊：使用 Google 登入時，Google 與 Supabase 會處理帳號識別碼、電子郵件地址及基本個人資料（例如名稱與頭像），用來辨識你的帳號、完成授權與維持登入。TagBible 不會取得你的 Google 密碼，也不要求讀取 Gmail 信件、Google Drive 檔案或聯絡人的權限。
  • 個人讀經紀錄：你設定的顯示名稱、頭像或上傳照片、閱讀設定、簽到、經文快照、標註、私人筆記與個人歷史。未登入時主要保存在本機；登入並啟用同步後，個人資料也會保存在 Supabase。
  • 小組互動：小組與成員關係、邀請碼、分享、回覆、阿們、完成讀經的日期與已讀狀態，用來提供小組互動、通知及讀經足跡。
  • 問題回報：你主動提供的內容、當時的顯示名稱、帳號識別碼、送出日期與處理狀態。回報由 TagBible 管理者在站內查看，不會公開為小組留言。
  • 必要技術資料：瀏覽器儲存的登入工作階段、同步快取、待送操作及偏好設定。主機與登入供應商也可能因安全與維運處理 IP 位址、請求時間、瀏覽器等技術資訊。

二、資料用途與 Google 資料

上述資料用於帳號登入、跨裝置同步、保存讀經紀錄、提供小組互動與通知、處理回報，以及維護服務安全。TagBible 目前不提供第三方廣告或販售個人資料。

Google 帳號資訊用於登入及帳號識別，不直接作為小組公開個人資料；小組顯示的是你在 TagBible 設定的名稱、頭像與分享內容。對從 Google API 取得資訊的使用及移轉，遵循Google API Services User Data Policy，包括其中的 Limited Use 要求。

三、哪些內容會分享

私人筆記及個人標註不會自動發送到小組，透過 App 存取個人雲端紀錄需登入對應帳號。這不是端對端加密服務，系統管理與服務供應商仍可能在必要的維運、支援、安全或法定範圍內處理資料。

小組分享與回覆會顯示給同組成員；你的顯示名稱、頭像或照片、完成讀經日期及連續完成狀態也會用於小組呈現。組長可管理成員及小組內容。成員可能自行截圖或轉傳，請避免分享未經同意的他人個資或不適合在小組流通的內容。

四、服務供應商與處理地點

TagBible 使用 Google 提供身分授權、Supabase 提供帳號及資料庫、Vercel 提供網站與伺服器託管；GitHub 用於網站程式及每日公開經文資料發布。這些供應商為提供服務，可能在不同國家或地區處理必要資料。個人筆記與小組資料不會作為公開 GitHub 程式碼發布。

供應商的資料處理亦受其政策規範：Google、Supabase、Vercel及GitHub。

五、保存、備份與刪除

讀經紀錄與互動歷史會為提供足跡功能而持續保存；留言板一次顯示的筆數，不代表更舊資料已刪除。目前透過 App 刪除小組分享、回覆或問題回報時，內容會從正常介面移除，但伺服器以刪除標記保留原始內容及作者資料，也會保留必要的操作收據與維運紀錄，以處理重試與安全需求。這個刪除操作不會永久抹除原始內容；如需永久清除，請另向管理者提出申請。備份及供應商日誌的保留依其服務機制與設定處理。

你可以從「我的設定 → 匯出備份」下載目前帳號或本機可用的個人紀錄。登出、清除本機紀錄或移除 Google 授權，不等於刪除 TagBible 的雲端資料或 Supabase 帳號。共用裝置使用後，請登出；需要清除本機快取時，可使用 App 的清除紀錄或瀏覽器網站資料設定。

若需查詢、更正或刪除帳號與雲端資料，請提出申請。管理者會先確認身分及申請範圍，再協助處理並說明必要保留項目。其他成員已下載、截圖或自行保存的副本，TagBible 無法直接控制。

六、聯絡與政策更新

請從「我的設定 → 問題回報」聯絡 TagBible 管理者，說明資料或隱私問題，勿提供密碼、驗證碼或其他登入憑證。若無法登入，可使用 Google 登入同意畫面列出的支援聯絡方式，或請原邀請人／小組組長協助聯絡管理者。

本政策可能隨服務功能或資料處理方式更新，最新內容與日期會公布於此頁；重大變更會另以適當方式說明。
