# 公開介紹及政策頁 — v0.15.4

新增/about/、/privacy/、/terms/及共用assets/info.css。頁面不載入App、SDK或API，不需JavaScript或登入；沿用EyeBible字標，支援320px手機、鍵盤焦點及系統亮暗色。歡迎與設定頁加入三個入口。Google首頁使用about/，能在登入前閱讀功能介紹與同站政策。

內容依實際帳號／個人紀錄／小組／回報程式撰寫：Google基本身份、Supabase儲存、本機工作階段及快取、私人與同組可見範圍、供應商與技術資料、歷史保留、匯出、登出／本機清除不等於雲端刪除、人工帳號資料申請。管理者私人信箱未公開；不虛構已完成Google審核、固定保留期限、自助刪帳或刪除SLA。政策請求與人工回覆是供擁有者確認的服務說明，不把未實測供應商後台當作驗證結果。

public-info.cjs先觀察公開路徑404，再觀察缺少App入口的失敗，修正後兩瀏覽器亮暗色、關JavaScript、手機溢出、鍵盤、站內導航、無外部／Auth請求及既有App入口皆通過。六個回歸腳本public-info／presentation／refinements／google-login／login-mobile／composers-feedback全數exit0。截圖檢視後，暗色字標沿用既有App濾鏡提升可辨識度，public-info再次通過。git diff --check通過。

一輪獨立審查在任何提交／PR之前，發現新測試的負向檢查包含私人信箱，已改成通用格式檢查並掃描全部可發布來源，私人值沒有進入Git提交。另以失敗測試補上刪除小組內容及回報的真實保存方式：正常介面隱藏，但伺服器保留原始內容與作者資料，永久清除需另申請。小字對比調整為4.95:1，暗色字標已檢視。沒有延期項目；實際Google聯絡資訊、品牌驗證、供應商保留設定與人工資料處理仍需擁有者確認。

正式界線：預覽可檢查內容，但有Vercel存取保護，不是給Google填的公開網址。另備從main產生、只新增四個靜態檔案的草稿PR，等待擁有者同意公開；不修改App、Auth、SQL、排程或data/。Google是否要求額外網域／品牌驗證以後台為準。本次沒有發布到main或對外聲稱通過Google審查。
