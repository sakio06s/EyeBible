# 匯出讀經筆記

在「讀經足跡」按「匯出筆記」：

1. 選「日期區間」並設定起訖日期，或選「聖經卷書」搜尋不限日期的紀錄。
2. 選擇「標記經文與出處」、「經文與個人筆記」或「全部小組留言與回覆」。
3. 選 Word（.docx）或 PDF（.pdf），按「產生檔案」。若裝置沒有自動下載，可再按下載連結。

日期區間包含起訖兩天。個人紀錄沿用讀經足跡的記錄日期；小組以留言發表的台北日期篩選，包含該則留言的所有回覆。按卷書匯出依章節排序，排除沒有連結該卷經文的一般聊天；跨卷筆記逐篇依實際經節篩選。經文出處使用完整書名、半形空格與章:節，例如「約翰福音 3:16–18」。

個人模式只包含目前帳號／本機自己的筆記，包含自己的私人筆記；小組模式只讀取目前加入小組的公開討論。檔案完全在裝置內產生，沒有上傳到文件轉換服務。所有分頁及回覆會讀取完畢；若匯出期間有留言置頂變動、資料不完整或帳號／小組切換，會取消檔案或提示重試。

Word 保留標記顏色並可編輯。PDF 文字可搜尋，保留顏色；為避免中文字缺字，嵌入完整中文字型，檔案約 4.4 MB 起，首次 PDF 產生需下載約 7 MB 字型。少數特殊符號以裝置字型圖形保存。

這個功能沿用現有小組讀取權限，不需新增 SQL。
